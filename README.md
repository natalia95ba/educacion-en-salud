# PAUSA · Interfaz React

## Requisitos
- Node.js 18 o superior
- npm

## Instalación y ejecución
```bash
npm install
npm run dev
```
Abre en el navegador la URL local que muestra Vite.

## Compilar para producción
```bash
npm run build
npm run preview
```

## Estructura
- `src/App.jsx`: pantallas, navegación y componentes.
- `src/styles.css`: estilos responsive.
- `src/assets/`: imágenes utilizadas en la interfaz.
- `src/main.jsx`: punto de entrada React.

## Navegación
La pantalla inicial muestra el contenido formativo. En el menú lateral, selecciona
«Fuerza y capacidad cardiovascular» para abrir el constructor de entrenamiento.

El menú lateral permanece fijo en escritorio y pasa a un panel desplegable en móvil.
La barra superior permanece fija en ambas pantallas.
