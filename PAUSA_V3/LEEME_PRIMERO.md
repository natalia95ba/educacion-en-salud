# Biblioteca PAUSA V3 — entrega funcional aprobada

La prescripción y el contenido editorial se consideran **aprobados por el profesional responsable**. No se solicita una nueva revisión profesional.

El paquete incluye datos de ejercicios, reglas, plantillas, motor Python de referencia, pruebas y ejemplos. **La web final todavía debe integrarse y completar las funciones técnicas indicadas en la guía.** No se debe confundir aprobación profesional con aplicación desplegada.

## Uso con Codex

1. Abrir `PAUSA_guia_integracion_codex_v3.md`. Fase 1: inspeccionar proyecto existente y proponer plan, sin modificar código.
2. Aprobar el plan. Fase 2: portar y completar motor, validar reglas y mostrar la interfaz definitiva.
3. Ejecutar `python PAUSA_pruebas_validacion_v3.py` para comprobar la referencia; ampliar pruebas en el lenguaje de la web.

## Entrega orientada al usuario

`PAUSA_vista_usuario_ejemplo_v3.html` ilustra cómo debe verse una sesión de un perfil generado. Es una **vista de ejemplo estática**, no reemplaza el generador interactivo ni la integración.
